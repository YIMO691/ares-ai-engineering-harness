# 行为准则

## 我们的承诺

参与者应以尊重、专业、可验证和面向问题的方式协作，不因角色、资历、背景或工具偏好贬低他人。

## 期望行为

- 对观点和证据进行评审，不攻击个人。
- 主动说明假设、不确定性、利益冲突和安全风险。
- 接受合理质疑，并允许新人提出流程问题。
- 在讨论流程时优先关注实际影响，而不是维护形式或权威感。
- 对敏感信息、公司数据和个人隐私保持克制。

## 不可接受行为

- 骚扰、歧视、威胁、侮辱或持续的人身攻击。
- 未经授权披露秘密、个人数据或内部材料。
- 伪造测试、证据、评审或 Gate 结论。
- 利用资历或权限阻止合理的技术和流程反馈。

## 执行

问题应通过私密渠道报告给仓库所有者 `@YIMO691`。维护者应根据事实采取提醒、限制参与、撤销访问或升级公司治理渠道等措施，并尽量保护报告者隐私。
