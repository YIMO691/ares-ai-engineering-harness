# 获取帮助

先把任务和 [仓库入口](README.md#从这里开始) 交给 AI。流程或文档问题可在本仓库反馈，业务代码缺陷留在目标项目。

| 遇到的问题 | 查阅位置 |
|---|---|
| AI 下一步该做什么，何时需要人决定 | [工作指南](docs/WORKFLOW.md) |
| 文档写什么、后来怎样继续修改 | [四类文档](templates/README.md) · [关联文档与后续修改](examples/L2-standard-feature.md) |
| AI 读不到项目或规范，长期接入工具 | [工具接入与排查](docs/AI_COLLABORATION.md) |
| 测试、失败恢复或评审遇到问题 | [工程规则](docs/ENGINEERING_RULES.md) |
| 暂停、换人或换工具后继续 | [交接规则](docs/WORKFLOW.md#中断与交接) |
| 旧模板或链接找不到 | [旧入口去向](docs/SOURCES.md#本次精简的旧入口) |

仍无法解决时，在 [Issues](https://github.com/YIMO691/Workflow-SOP/issues) 提供所用版本、具体场景、预期与实际情况、已尝试内容；已有讨论直接补充。不要求原始日志或业务源码，敏感问题按 [安全说明](SECURITY.md) 处理。改进文档见 [贡献指南](CONTRIBUTING.md)，参与讨论遵循 [行为准则](CODE_OF_CONDUCT.md)。
