# 安全策略

## 支持范围

当前只维护默认分支 `main` 的最新版本。历史试运行版本不单独提供安全更新。

## 报告安全问题

不要在普通 Issue、PR、讨论、示例或日志中公开秘密、凭据、个人数据、内部仓库信息或其他敏感材料。

发现安全问题时，请优先使用仓库 Security 页面中的私密安全通告功能联系维护者；若该功能不可用，请通过 GitHub 私密渠道联系仓库所有者 `@YIMO691`，只提供定位问题所需的最小信息。

报告建议包含：

- 受影响文件或工作流环节。
- 风险和可能影响。
- 最小复现步骤。
- 已知缓解方式。

维护者确认安全范围前，请勿创建公开 Issue 或提交包含利用细节的 PR。

## AI 使用安全

- 不向未获批准的 AI 服务上传公司代码、生产数据、凭据或个人信息。
- AI 生成内容必须由有权限的人检查，不能把模型输出当作安全审计结论。
- 涉及权限、资金、隐私、密钥、数据迁移或不可逆操作时，必须按 L3 和项目安全规范处理。
