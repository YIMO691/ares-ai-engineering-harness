# 安全说明

本仓库提供试行工作方法，不构成安全审计认证或统一的公司授权系统。目标项目的访问、资料外发、代码审查与发布要求仍需遵守。

## 内容边界

只提交经允许共享的规范、模板和脱敏示例。不要把凭据、生产数据、个人信息、内部运行日志或未经授权的业务代码写入 Issue、PR、示例或 AI 输入。项目配置允许的 AI 服务与资料使用范围，见 [项目规则模板](templates/PROJECT-RULES.md)。

涉及敏感数据、重要权限或难回滚变化时，安排与风险相称的验证及独立判断；不因风险关键词强制增加整套文档。AI 输出与自动检查不能替代实际安全证据。

## 报告问题

通过团队已建立的私密沟通渠道联系维护者 @YIMO691；若仓库已启用私密漏洞报告，也可使用其 Security 页面。未确认私密渠道前不要创建含敏感细节的普通 Issue。

提供受影响版本、问题位置、可能影响和必要的脱敏复现信息即可。当前只维护主线最新规范，历史基线用于追溯，不承诺独立维护。
