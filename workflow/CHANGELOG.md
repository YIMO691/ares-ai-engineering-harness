# Changelog

本文件记录工作流包的重要变化。

## [0.4.0] - 2026-09-01

- 增加正式功能模板包，形成 PRD、SDD、TEST-PLAN、DELIVERY 和按需 ADR 的完整正规流程。
- 为模板章节标注必填、条件必填和可选，兼顾完整性与按风险裁剪。
- 增加 DELIVERY，统一承载实施结果、测试结果、偏移、Align 和最终交付决定。
- TEST-PLAN 回归测试设计职责，不再与交付文档重复维护执行状态。
- 同步 SOP、任务分级、AI 操作层、L3 示例和自动校验规则。

## [0.3.0] - 2026-09-01

- 增加 START-HERE、AGENTS、AI-PLAYBOOK 和三个 AI 提示词。
- 固定 AI 的工程探索、任务分级、输出契约、停止条件和证据规则。
- 增加 GitHub Issue/PR 模板、贡献、安全、行为准则、CODEOWNERS 和验证 CI。

## [0.2.0] - 2026-09-01

- 增加 Align Gate 和分层权威模型。
- 根据完整试运行优化 TDD 重复、分级留证和偏移处理。

## [0.1.0] - 2026-09-01

- 建立 L1/L2/L3、Ready/Build/Done、基础模板和三级示例。
