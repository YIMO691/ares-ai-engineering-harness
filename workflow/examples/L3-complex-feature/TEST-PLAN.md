# 1. 测试目标与范围

证明导出任务在正常、重复、越权、超时和存储失败场景下保持正确状态，不泄露数据，并满足可恢复与清理要求。

# 2. 测试策略

- 单元测试：状态机、参数规范化、去重、错误分类。
- 集成测试：任务领取、分页查询、对象上传、权限校验和清理。
- 端到端测试：创建、查看进度、完成下载、失败重试和过期。
- 专项测试：执行器故障注入、容量边界和敏感字段访问。

# 3. 需求与测试映射

| 验收项/风险 | 测试名称或场景 | 层级 | 自动化 | 通过标准 |
| --- | --- | --- | --- | --- |
| AC-01 | Create_ReturnsBeforeGeneration | 集成 | 是 | 2 秒内返回任务 ID |
| AC-02 | Query_RejectsOtherOwner | 集成 | 是 | 返回无权访问且无任务信息泄露 |
| AC-03 | Download_RechecksPermission | E2E | 是 | 撤权后拒绝生成地址 |
| AC-04 | WorkerLease_RecoversAfterCrash | 故障注入 | 是 | 任务恢复且仅有一个最终文件 |
| AC-05 | Cleanup_ExpiresAndDeletesObject | 集成 | 是 | 文件删除、任务为 Expired |

# 4. 环境与数据

使用隔离测试租户、测试队列和对象存储桶。准备有权限、撤权、跨租户、空数据和超过最大行数的数据集；测试结束后按任务 ID 清理。

# 5. 核心、异常与边界场景

- 空结果生成仅含表头的有效 CSV。
- 重复创建复用未完成任务，窗口外创建新任务。
- 两个执行器竞争时只有一个领取成功。
- 查询中断、上传超时和状态提交失败均进入预期恢复路径。
- CSV 特殊字符、换行、公式前缀和编码符合安全输出规则。
- 用户撤权、跨租户和过期任务均不能下载。

# 6. 专项测试

- 逐步增加行数验证内存稳定、最大行数和超时限制。
- 注入执行器退出、队列重复投递、存储暂时不可用和清理失败。
- 检查日志不包含导出数据和签名地址。
- 验证关键指标和告警能够定位积压与失败。

# 7. TDD 执行约定

状态机、幂等去重、权限规则和已发现缺陷必须测试先行；浏览器布局与下载交互可通过组件测试和端到端测试验证。

# 8. 测试退出条件

- [ ] 所有 Must 验收项通过。
- [ ] 权限、跨租户和敏感字段检查通过。
- [ ] 故障恢复、过期清理和监控演练通过。
- [ ] 容量限制与灰度开关完成配置。
