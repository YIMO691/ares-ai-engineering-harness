# 目标

在现有 Ready、Build、Done 流程中增加一个轻量但明确的 Align Gate，使需求、设计、契约、测试和最终实现发生偏移时必须在任务关闭前解决。

# 为什么按 L3 管理

这是公司级工作方式的长期变更，会影响产品、开发、测试和评审者；“什么是权威”属于重大且难以随意改变的治理决定。

# 验收标准

- AC-01：SOP 明确 Align Gate 的进入时机、检查内容、失败处理和通过条件。
- AC-02：不同信息类型只有一个明确权威来源，不把所有文档笼统定义为高于代码。
- AC-03：L1/L2 不新增独立审批或强制文档，L3 可按风险保留对齐证据。
- AC-04：交付检查能够发现需求、设计、契约、测试和实现之间的偏移。
- AC-05：完整走一遍当前流程，并记录由此发现的模板问题与优化结果。
