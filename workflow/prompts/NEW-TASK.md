# 新任务启动提示词

复制下面内容交给 AI，删除不适用的提示文字并填写括号内容。

```text
请按照项目中的 UPSTREAM-AGENTS.md 和 AI-PLAYBOOK.md 处理此任务。

项目或代码位置：<路径、仓库或已上传材料>
原始需求：<按原意填写，不必先改写成专业术语>
期望结果：<分析 / 设计 / 实现 / 评审 / 修复并验证>
已知成功标准：<没有时写“待梳理”>
明确不做：<没有时写“待梳理”>
约束：<时间、兼容、安全、平台、存储、不可修改区域等>
允许的操作：<只读检查 / 允许修改代码 / 允许运行测试等>

先检查工程和已有文档，不要询问能够从工程发现的问题，也不要立即生成全部模板。

第一次回复必须给出：
1. 当前 Ready Gate 的 Pass/Fail；
2. 任务理解；
3. 工程现状与证据位置；
4. L1/L2/L3 等级、理由和最低必要产物；
5. 范围、非目标和可验证 AC；
6. 功能点拆解，包括依赖、风险和验证方式；
7. 只有我才能决定的剩余问题；
8. 下一步。

如果没有关键决策缺失，并且我已授权实现，请继续推进必要的 Build、实现和验证；不要为了等待形式确认而停止。
```
